# Changelog

## [Unreleased]

### Changed
- Removed `sudo` from most commands in various repositories, assuming the user has appropriate permissions or will run the command with elevated privileges when necessary.
- Updated `shelldock sync` command to require `sudo` for updating the bundled repository.
- Modified command execution to use `powershell` on Windows instead of `sh`.
- Improved platform detection and command fallback logic for Linux distributions.
- Updated various package installation commands to reflect changes in package managers (e.g., `apt-get` to `apt`).
- Changed the way swap file creation and management commands are handled, removing `sudo` where applicable.

### Removed
- Removed the `repository/nodejs.yaml` file, as its functionality is now covered in `repository/languages/nodejs.yaml`. 

### Fixed
- Fixed the logic for determining the command to use based on the platform, improving how commands are selected and executed across different operating systems.
- Improved error handling and logging for command execution, especially for cases where `sudo` is not used.
- Resolved issues with command formatting and consistency across different repositories and platforms. 

### Added
- Added support for Windows in several repositories, including commands for installing and managing software.
- Enhanced the `sysinfo` repository with additional commands for displaying system information on Windows.
- Improved documentation and comments throughout the codebase for better clarity and maintainability.
