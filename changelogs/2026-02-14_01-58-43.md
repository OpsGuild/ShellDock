# Changelog

## [Unreleased]

### Added
- Support for waiting for SSH service to be ready after installation
- Configuration of SSH firewall rule to allow port 22
- Allow ICMP ping for external connectivity checks
- Display SSH connection information after setup
- New version "v2" for generating SSH key pair and configuring SSH client
- Support for creating .ssh directory with correct permissions
- Generation of SSH key pair with customizable key type, size, comment, and passphrase
- Setting correct permissions on key files
- Display of public key for addition to remote servers
- Starting SSH agent and adding key

- Updated description of version "v1" to include installation and configuration of OpenSSH server and client
- Renamed tag for version "v1" to "install"
- Updated command for configuring SSH firewall rule to include more platforms
- Updated command for verifying SSH service status to include more platforms
- Added more platforms for displaying SSH connection information

- No fixes are included in this release
