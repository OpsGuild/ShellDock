# Changelog

## [Unreleased]

### Added
- New version "v3" for authorize tag, which includes steps to authorize a public key for incoming SSH connections.
- Steps to create authorized_keys file with correct permissions, add public key to authorized_keys, copy key to administrators authorized_keys (on Windows), set correct permissions on authorized_keys, enable public key authentication in sshd_config, restart SSH service, and display connection information.
- Default comment for key generation set to "shelldock-key".

### Changed
- Argument collection logic in `collectCommandArgs` function now includes empty values in the result map.
- Key generation now uses "shelldock-key" as the default comment.
