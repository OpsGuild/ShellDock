# Changelog

## [Unreleased]

### Added
- Cross-platform sandbox tests using Docker, allowing for testing on multiple platforms including Ubuntu, Debian, Rocky Linux, Fedora, Arch Linux, and Windows.
- New `test-sandbox` and `test-sandbox-build` targets in the Makefile to run sandbox tests and build shelldock for Linux/amd64, respectively.
- Support for running sandbox tests on macOS using the `sandbox-test-darwin` workflow.
- Ability to customize sandbox tests by specifying a platform, command, or skipping Docker image rebuild using the `PLATFORM`, `COMMAND`, and `BUILD` variables.
