# Changelog

## [Unreleased]

### Added
- New command `shelldock add <name>` to create local command sets (either from bundled templates or as new empty templates)
- New command `shelldock open <name>` to open command set YAML files in your preferred editor
- New command `shelldock rm <name>` to remove local command sets
- New command `shelldock upgrade` to automatically upgrade the ShellDock binary to the latest version
- Alias `shelldock ls` for the existing `list` command
- Alias `shelldock update` for the existing `sync` command
- New flags for `add` command: `--open`, `--editor`, `--description`, and `--version`
- New flags for `open` command: `--editor`
- New flags for `rm` command: `--yes`
- New flags for `upgrade` command: `--dry-run` and `--yes`

### Changed
- Improved `shelldock sync` command with better error handling and confirmation prompts
- Updated bash completion to include new commands and aliases
- Refactored sync logic into a reusable function shared by both `sync` and `update` commands

### Fixed
- Minor documentation formatting issues (removed trailing whitespace in BASH_COMPLETION.md)
