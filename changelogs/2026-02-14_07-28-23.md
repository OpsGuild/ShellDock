# Changelog

## [Unreleased]

### Added
- Support for GNU timeout command on macOS by installing coreutils
- Portable fallback for timeout functionality on systems without GNU timeout

### Changed
- Updated `run_with_timeout` function to use GNU timeout if available, and a portable fallback otherwise
- Renamed `timeout` variable to `duration` in `run_with_timeout` function for clarity
- Updated PATH environment variable to include coreutils binary directory

### Fixed
- Improved handling of timeout errors in `run_with_timeout` function to provide consistent behavior across different systems
