# Changelog

## [Unreleased]

### Changed
- Shell execution behavior now respects the `SHELLDOCK_USE_LOGIN_SHELL` environment variable to control whether to use login shell flags (`-lc`) or regular shell flags (`-c`). Set to "1", "true", or "yes" to enable login shell behavior.
- Improved sync command output with a clearer "Downloading command sets..." message.

### Fixed
- Removed redundant shell name checks that were previously used to determine login shell support. The behavior is now controlled entirely by the environment variable.

### Removed
- The automatic detection of shell types for login shell support (previously checked for bash, zsh, fish, etc.). This is now controlled by the `SHELLDOCK_USE_LOGIN_SHELL` environment variable.
