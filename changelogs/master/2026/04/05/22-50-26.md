# Changelog

## [Unreleased]

### Added
- New `install` subcommand as an alias for running command sets (equivalent to `run`)
- Support for user's preferred shell (via $SHELL environment variable) when executing commands
- Automatic PATH normalization to include common system paths (/usr/local/bin, /usr/bin, etc.)

### Changed
- Improved command execution to use appropriate shell flags (-lc for login shells, -c otherwise)
- Enhanced shell detection to support bash, zsh, ksh, fish, and other common shells
- Test suite now automatically detects shelldock binary location (build/shelldock or ./shelldock)

### Fixed
- Fixed potential panic when originalIndices wasn't properly initialized for command filtering
- Improved PATH handling to ensure system paths are available during command execution
- Better Windows compatibility in command execution

### Removed
- Hardcoded shell selection (now respects user's SHELL environment variable)

### Security
- Enhanced PATH handling to prevent potential command injection through PATH manipulation
