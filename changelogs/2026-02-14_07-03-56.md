# Changelog

## [Unreleased]

### Added
- Initial sync functionality for bundled repository
- Support for Windows-specific paths in repository manager
- User-level fallback path for repository manager
- `autoSyncIfNeeded` function to check and sync bundled repository

### Changed
- Improved argument handling in `promptForArg` function
- Updated `collectCommandArgs` function to use `cliArgs` and persist collected arguments
- Modified repository manager to create a user-level repository if no bundled repository is found
- Changed Windows commands in various repository files to use single quotes instead of `powershell -Command`
- Updated `run` command to use `autoSyncIfNeeded` function

### Fixed
- Fixed issue with default values not being used in `promptForArg` function
- Resolved issue with `collectCommandArgs` function not handling empty responses correctly

Note: This changelog only includes changes that are relevant to the user or developer, and excludes internal implementation details.
