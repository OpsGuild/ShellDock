# Changelog

## [Unreleased]

### Changed
- Improved Windows network reset commands to specify the interface and provide more detailed output.
- Updated Windows DHCP service restart command to only restart the DHCP service.
- Modified Windows network stack reset command to disable and re-enable the network adapter instead of resetting winsock and IP.
- Enhanced Windows network status check command to provide more detailed information about the interface status, IP configuration, DNS test, and connectivity test. 
- Changed the Windows network status check command to handle cases where no IPv4 address is assigned or DNS resolution fails.
